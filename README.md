# درباره این مخزن

This repository contains the Python examples, exercises and educational files created during the Python P7 course at Fanavari Tehran.

Each class session has a separate folder containing the related examples and practice files.

The repository helps students:

Review topics covered in class
Run and modify Python examples
Practice programming concepts
Follow their progress throughout the course
Become familiar with Git and GitHub

# توضیح فایل‌ها


## فایل‌های ریشه مخزن

| فایل | توضیح |
|------|--------|
| `README.md` | معرفی دوره، مشخصات کلاس و راهنمای همین مخزن. |
| `.gitignore` | فهرست فایل‌هایی که گیت نباید ذخیره کند (مثل `.DS_Store`). |
| `L1_1.md` | **جلسه اول — بخش تئوری.** تاریخچه ذخیره عدد، سیستم دودویی، تفاوت زبان انسان و ماشین، نقش زبان برنامه‌نویسی، نصب پایتون و آناکوندا، و معرفی ادیتور و IDE. |
| `L1_2.py` | **جلسه اول — کد عملی.** اجرای اولین برنامه (`print`)، توابع داخلی، کلمات کلیدی، ساخت متغیر، قوانین نام‌گذاری، عدد (`int` / `float` / `complex`)، عملیات ریاضی و مقایسه، بولین و رشته. در انتهای فایل تمرین‌های جلسه اول آمده است. |
| `L2.py` | **جلسه دوم.** توابع داخلی مثل `abs`، `input` و تبدیل نوع (`int`/`float`/`str`)، ایندکس و اسلایس رشته، متدهای `str`، لیست و متدهای آن، سپس تاپل، مجموعه (`set`) و دیکشنری. |
| `L3.py` | **جلسه سوم.** دستورات شرطی: `if`، `if-else`، `elif`، ترکیب شرط با `and`/`or`، شرط تو در تو، مثال فروشگاه و کد تخفیف. در انتها کوئیز جلسه سوم آمده است. |
| `L4.py` | **جلسه چهارم.** مرور شرط‌ها با ماشین‌حساب و نمره‌دهی، سپس حلقه `for`: تکرار ثابت، تکرار پویا و پیمایش لیست. در انتها ۱۲ تمرین شرط و حلقه آمده است. |
| `L5.ipynb` | **جلسه پنجم — نوت‌بوک ژوپیتر.** معرفی محیط `.ipynb`، مرور شرط و حلقه، پیمایش لیست، `enumerate` و `zip`، و شروع مبحث حلقه `while`. |
